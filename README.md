<details>
<summary>🐍 Not animating? Here's how it works</summary>

The snake is generated by [`.github/workflows/snake.yml`](.github/workflows/snake.yml), which renders the
contribution grid into two SVGs and pushes them to the **`output`** branch. The README links to that branch,
so the images stay broken until the workflow has run **at least once**.

**First-time setup:**

1. Push this repo (the workflow triggers on push to `master`).
2. Open the **Actions** tab → **Generate Snake** → **Run workflow**.
3. Confirm an `output` branch now exists with `github-snake.svg` and `github-snake-dark.svg`.

After that it regenerates automatically every 12 hours.

**If the run fails at the push step,** enable write access:
**Settings → Actions → General → Workflow permissions → Read and write permissions**.

</details>
